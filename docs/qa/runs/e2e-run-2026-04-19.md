- **원인**: Agent `compare_districts` tool 은 CompareCard 만 발행하고 `map_cmd(addToCompare)` 이벤트는 미발행
- **선택지**:

  2. 프론트 `eventHandlers.ts`에서 `card_type === 'comparison'` 수신 시 compareList 자동 동기화
  3. 테스트를 UI flow (Toolbar 토글 + polygon click) 로 수정
