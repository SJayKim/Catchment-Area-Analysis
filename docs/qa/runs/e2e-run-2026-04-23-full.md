### 2.6 Memory 업데이트 후보

- **`feedback_env_e2e_crlf.md`** — `.env.e2e` 가 CRLF 로 저장돼 있으면 `preflight.sh` 의 empty-value 체크가 `\r` 때문에 실패. `sed -i 's/\r$//' .env.e2e` 로 복구.
- **`feedback_postgis_init_race.md`** — fresh volume 으로 e2e stack 최초 기동 시 `pg_isready` 가 초기화 중 false-positive healthy → migrate 의 psycopg2 connect 실패. `until psql SELECT 1` 폴링 후 `up -d` 재시도로 복구.
- **`feedback_selector_collision_h8.md`** — Tailwind 유틸리티 클래스 (`.h-8`, `.w-8` 등) 를 spec 셀렉터로 쓰면 5곳 이상 매칭되어 `.first()` 가 엉뚱한 요소 집음. **항상 `data-testid` 권장**.
- **`feedback_playwright_image_no_python.md`** — `mcr.microsoft.com/playwright:*-jammy` 이미지에 `python` 명령 없음 (`python3` 만). spec 내 `spawnSync('python', ...)` 는 ENOENT 즉시 실패 (`r.status === null`). 기본값 `python3` 또는 `E2E_PYTHON=python3` 명시.
- **`feedback_locator_getAttribute_infinite_wait.md`** — Playwright `locator.getAttribute()` 는 default action timeout 이 unlimited. 요소가 영구 부재하면 `.catch()` 가 fire 안 하고 테스트 timeout 까지 대기. **element 유무 조건부 로직은 `await loc.count() === 0` 선검사**.
