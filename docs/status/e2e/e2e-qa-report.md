## 수정 완료 버그 (2건)

### 1. Top 5 업종에 점포 수 0개 업종 포함
- **파일**: `server/server/agent/tools/store_info.py`
- **원인**: `ORDER BY store_count DESC LIMIT 5` 쿼리에 `store_count > 0` 조건 없음
- **수정**: `.where(Store.store_count > 0)` 필터 추가

### 2. 채팅에서 상권 전환 시 지도/Card 미갱신
- **파일**: `server/server/api/routes/chat.py`
- **원인**: "명동**은** 어때?"에서 조사 "은" 포함된 "명동은"으로 DB 검색 → 매칭 실패
- **수정**: `_strip_korean_particles()` 함수 추가 — 한국어 조사 15종 제거 후 검색

## 잔여 SOFT FAIL (1건)

### T3.8.2 — "여기 카페 많아?" 컨텍스트 불일치
- **현상**: 지도/StatusBar는 강남역 선택 상태인데, AI가 성수동카페거리 데이터로 응답
- **원인**: Agent LLM이 "카페" 키워드를 보고 자체 판단으로 카페 관련 상권을 선택한 것으로 추정
- **심각도**: 낮음 (대부분의 컨텍스트 유지는 정상 동작)
- **개선 방안**: 시스템 프롬프트에 "사용자가 상권을 명시하지 않으면 현재 선택된 상권 컨텍스트를 유지할 것" 강화
