## TEST 1: 강남역 상권 종합 분석

**Query**: "강남역 상권을 종합 분석해줘. 유동인구, 매출, 점포 현황, 인구 특성을 모두 알려줘."

### 프로세스 흐름

```
User Query
  → [THINKING] 분석 중...
  → [TOOL] get_floating_population_tool(D3001, 2025Q3)
  → [TOOL] get_estimated_sales_tool(D3001)
  → [TOOL] get_store_info_tool(D3001)
  → [TOOL] get_population_info_tool(D3001)
  → [THINKING] 분석 중... (Tool 결과 종합)
  → [TEXT] 스트리밍 응답 (18 chunks)
  → [SUGGESTION] 후속 질문 4개
  → [DONE]
```

### SSE 이벤트 흐름
`thinking → tool → tool → tool → tool → thinking → text → suggestion → done`

### AI 응답 (전문)

강남역 상권(D3001)에 대한 2025년 3분기 종합 분석 결과입니다.

**1. 유동인구 현황 (2025Q3 기준)**
- 일평균 유동인구: 약 124,350명
- 성별 분포: 남성 52.3%, 여성 47.7%
- 연령별 분포: 30대(32.1%)가 가장 많고, 20대(28.5%), 40대(18.7%) 순
- 피크 시간대: 오후 6시 (18시)

**2. 추정 매출 현황 (2025Q3 기준)**
- 월 추정 총 매출: 약 85.2억 원 (카드 매출 기반, 현금 미포함)
- 매출 추이: 지속 성장 (2024Q4 78억 → 2025Q3 85.2억)
- 주요 매출 시간대: 17시~21시 (23.4억), 11시~14시 (21.3억)
- 주중 매출이 주말 매출의 약 2배

**3. 점포 현황 (2025Q3 기준)**
- 총 1,852개 점포 (개업 125, 폐업 98, 폐업률 5.3%)
- Top 업종: 한식(245), 커피/음료(198), 의류(165), 일식/중식(132), 미용/뷰티(118)

**4. 인구 특성 (2025Q3 기준)**
- 상주인구: 32,500명 (30대·20대 중심)
- 직장인구: 185,000명 (30대·40대·20대)

- [x] 모든 Tool이 Mock 데이터 정상 반환
- [x] 데이터 기준 분기(2025Q3) 명시

## TEST 2: 홍대 vs 건대 상권 비교

**Query**: "홍대입구랑 건대입구 상권을 비교 분석해줘. 어디가 더 좋아?"

### 프로세스 흐름

```
User Query
  → [THINKING] 분석 중...
  → [TOOL] compare_districts_tool(["D3002", "D3008"])
  → [THINKING] 분석 중... (결과 해석)
  → [TEXT] 스트리밍 응답 (5 chunks)
  → [SUGGESTION] 후속 질문 4개
  → [DONE]
```

### AI 응답 요약

Agent가 `compare_districts_tool`을 호출했으나, 건대입구를 D3008로 매핑 (실제로는 D3003).
→ 홍대입구 데이터만 반환되어 부분 응답 생성.

**홍대입구 상권 (2025Q3)**:
- 유동인구: 일평균 98,700명
- 주 연령대: 20대
- 총 점포: 1,425개
- 월 매출: 63.5억원
- 폐업률: 8.3%

### 발견된 이슈
- **District Code 매핑 미스**: Agent가 "건대입구"를 D3003이 아닌 D3008로 매핑
- 원인: 시스템 프롬프트에 상권코드 목록이 없어 LLM이 코드를 추측
- 해결 방안: 시스템 프롬프트에 사용 가능한 상권 목록 추가 필요

### 검증 포인트
- [x] Agent가 "비교해줘" 키워드에 compare_districts_tool 선택
- [x] 부분 데이터로도 graceful한 응답 생성 (에러 대신 가용 데이터 제공)
- [ ] 상권코드 정확한 매핑 (개선 필요)

## 코드 수정 사항 (테스트 과정에서 발견/수정)

### 1. `server/server/config.py` — .env 경로 수정
**문제**: Settings가 현재 디렉토리의 `.env`만 탐색 → 프로젝트 루트 `.env` 미로드
**수정**: `Path(__file__).parents[2] / ".env"` 절대 경로로 변경

### 2. `server/server/config.py` — extra fields 허용
**문제**: `.env`의 `NEXT_PUBLIC_KAKAO_MAP_KEY`가 Settings에 없어 ValidationError
**수정**: `model_config`에 `"extra": "ignore"` 추가

### 3. `server/server/agent/graph.py` — LLM Provider 전환 지원
**수정**: `LLM_PROVIDER` 설정으로 Gemini/Anthropic 동적 전환
- `llm_provider: str` (config)
- `_create_llm()` 함수로 provider별 LLM 인스턴스 생성
