## 3. Design

### 3.1 W1 entity_matching ("시장" boost · paren-self 가드)

**현 문제**:
- `"남대문시장"` → `삼익패션타운(남대문시장)` (paren_exact +0.15) 으로 self-match 인 `남대문시장(자유상가)` 보다 높을 수 있음.
- `TYPE_PRIORITY` 에서 전통시장(rank 1, +0.05) 가 발달(+0.20) · 골목(+0.10) 보다 낮아 시장명 쿼리 시 불리.

**Fix**:
1. `_market_query_boost(query, name, dtype)` 추가:
   - query 가 `"시장"` 으로 끝나고 `dtype == "전통시장"` 이면 `+0.15`
2. `_paren_and_root_bonus` 가드:
   - paren 내부 토큰이 query 와 exact 매치 + name 의 root 가 query 와 다르면 → bonus 절반(`_PAREN_EXACT_BONUS / 2 = 0.075`). self-name 매치(prefix or exact) 가 항상 우선되도록 함.
3. unit test 추가 (`server/tests/test_entity_matching.py`): "남대문시장" / "홍대" / "성수" 회귀.
