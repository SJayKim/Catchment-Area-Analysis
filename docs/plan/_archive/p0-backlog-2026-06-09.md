## Item 1 — ISSUE-003: recommend_business 저점포수 랭킹 아티팩트 (server)

### 근본 원인 (확정)
`server/server/repositories/real/recommendation.py:153`
```python
raw_score = (per_store_sales * age_match * (1 - close_rate)) / max(competition, 0.01)
```
저점포수 카테고리를 **이중으로** 띄운다:
- **L153 ← L127** `per_store_sales = monthly_sales / store_count` — n=1이면 카테고리 전체매출이
  통째로 '점포당'으로 잡힘(2억). 표본 1개는 통계적 의미 없음.
- **L153 ← L128** `competition = store_count / total_stores_in_district` 가 분모(하한 0.01) —
  희소 카테고리는 ×100까지 증폭, 정상 카테고리는 ~×19. 즉 희소가 ~5x 추가 유리.
- 정규화(L195-200) min-max 스케일 → 아티팩트가 score 100 으로 1순위 고정.

Mock 레포(`repositories/mock/recommendation.py`)는 fixture 기반이라 이 공식을 안 탄다 → **변경 불필요**.

### Fix — 점포수 플로어 + graceful fallback (순수함수 추출)
`recommendation.py` 에 모듈 레벨 상수 + 순수함수 1개 추가하고, 스코어링 루프 직후
(현 L181 `filtered = raw_scores`) 에서 호출한다.

```python
MIN_RELIABLE_STORES = 3  # n<3 카테고리는 per-store 지표가 통계적으로 무의미

def _apply_store_floor(scored: list[dict]) -> tuple[list[dict], bool]:
    """표본 부족(store_count < floor) 카테고리를 랭킹에서 제외.
    플로어 통과 카테고리가 0이면(작은 골목상권) 전체로 fallback 하고 low_confidence=True."""
    reliable = [s for s in scored if s.get("store_count", 0) >= MIN_RELIABLE_STORES]
    if reliable:
        return reliable, False
    return scored, True
```

L181 교체:
```python
filtered, low_confidence = _apply_store_floor(raw_scores)
```
- 이후 preference/budget 필터·정규화·top5 정렬(L183-204)은 `filtered` 기준 그대로 동작.
- 결과 dict 에 fallback 안내 메시지 추가(기존 budget message 와 동일 패턴, L223-234):
  `low_confidence` 시 `"점포 표본이 적어(<3개) 참고용 추천입니다"`.

루프 내부(per-category 계산)는 손대지 않음 — 플로어는 루프 직후 파티션. 변경 ~8줄.

### 회귀 테스트 (fail-without / pass-with)
신규 `server/tests/test_recommendation_scoring.py`:
- `test_store_floor_excludes_single_store_category` — 편의점(store_count=1, raw 1e10) +
  카페(store_count=50, raw 3e8) → `_apply_store_floor` 결과에 **편의점 없음, 카페 있음**,
  `low_confidence is False`. (플로어 없으면 편의점이 1순위 → 테스트 실패.)
- `test_store_floor_fallback_when_all_below_threshold` — 전부 n<3 → 전체 반환 +
  `low_confidence is True` (빈 추천 방지 보증).
- `test_min_reliable_stores_constant` — 상수 sanity.

기존 `test_repos_mock.py::test_recommendation_returns_data` 는 그대로(회귀 가드).

### 검증
```
cd server && ruff check . && ruff format --check .
cd server && pytest tests/test_recommendation_scoring.py tests/test_repos_mock.py -q
```
- 선택적 실데이터 smoke: 성수동 추천 요청 → 1순위가 점포 ≥3 카테고리인지, 편의점 1점포가
  top5 에서 빠졌는지 SSE/카드로 확인(Item 4 eval 에서 자연 커버).

### 변경 파일
- `server/server/repositories/real/recommendation.py` (상수+순수함수+L181+메시지)
- `server/tests/test_recommendation_scoring.py` (신규)
