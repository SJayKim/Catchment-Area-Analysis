# MarketScope AI — 사용 안내

> 지도에서 상권을 클릭하고, AI에게 자연어로 물어보세요.
> 소상공인·부동산 투자자를 위한 서울시 상권분석 서비스.

---

## 1. 무엇을 할 수 있나요?

**지도 기반 AI 챗봇으로 서울시 상권을 분석합니다.**
상권을 클릭하거나 검색하면 AI가 유동인구·매출·점포 데이터를 읽고 바로 분석해 줍니다.

### 지원 기능

| 기능 | 예시 질문 | 결과 |
|------|-----------|------|
| **상권 기본 리포트** | "강남역 분석해줘" | 유동인구·매출·점포 요약 + 시간대별 차트 |
| **상권 비교** | "강남역이랑 홍대 비교해줘" | 지표별 비교표 + 우위 분석 |
| **업종 추천** | "여기서 뭐하면 좋을까?" | Top 5 업종 + 추천 근거 |
| **리스크 분석** | "여기 창업하면 위험해?" | 폐업률·생존기간·위험 업종 경고 |
| **매출 시뮬레이션** | "여기서 카페 열면 매출 얼마나?" | 하위/평균/상위 예상 매출 범위 |
| **시간대별 히트맵** | 지도 상단 히트맵 버튼 | 0~23시 유동인구 시각화 (재생 가능) |
| **PDF 저장** | "PDF로 저장해줘" | 분석 내용 + 차트가 담긴 리포트 다운로드 |

### 데이터 커버리지

- **지역**: 서울시 전역 **1,650개 상권** (발달상권 / 골목상권 / 전통시장 / 관광특구)
- **데이터 기준**: 2025년 4분기 (서울 열린데이터광장)
- **포함 데이터**:
  - 유동인구 (시간대·요일·연령·성별)
  - 추정매출 (업종·분기별)
  - 점포 현황 (개업·폐업·프랜차이즈)
  - 상주/직장인구
  - 점포 이력 (공공데이터 제공 범위 내)

> 서울시 외 지역, 실시간 데이터, 개별 매장 매출은 지원하지 않습니다.

## 2. 사용 시나리오

### 시나리오 A. 카페 창업을 고민하는 예비 소상공인

> "강남역에 카페 열까 고민 중인데, 괜찮을까?"

1. 지도에서 **강남역 발달상권** 클릭 → 기본 리포트 자동 표시
2. 채팅에 **"여기서 카페 열면 매출 얼마나 나올까?"** 입력 → 매출 시뮬레이션 카드
3. **"이 자리 카페 위험하지 않아?"** → 폐업률·생존기간 리스크 분석
4. **"홍대랑 비교해줘"** → 두 상권 비교표로 의사결정
5. 상단 **PDF 버튼**으로 분석 내용 저장

### 시나리오 B. 업종을 정하지 못한 투자자

> "이 상권에서 뭘 하면 가장 잘 될까?"

1. 지도에서 관심 상권 클릭
2. **"여기 뭐하면 좋을까?"** → Top 5 업종 추천 + 점수·근거 제공
3. 추천 업종 중 하나 골라 **"카페 매출 시뮬레이션해줘"** → 구체적 매출 범위
4. **"이 상권 리스크는?"** → 폐업 위험 업종 확인

### 시나리오 C. 지역 특성을 확인하고 싶은 부동산 관계자

> "이 동네 사람들 언제 제일 많이 다녀?"

1. 지도 상단 **히트맵 토글** 클릭 → 유동인구 히트맵 표시
2. **시간 슬라이더** 드래그 or 재생 버튼 → 0~23시 유동인구 변화 애니메이션
3. 관심 상권 클릭 → **"시간대별 유동인구 알려줘"** → 차트로 피크 시간 확인

## 3. 바로 시작하기

1. **서비스 접속** → 좌측에 서울 지도, 우측에 채팅 패널이 보입니다.
2. **상권 선택** — 두 가지 방법:
   - 지도에서 색칠된 폴리곤 **클릭**
   - 상단 검색창에 **상권명 입력** (예: "강남역", "홍대입구")
3. **AI에게 질문** — 아래 문장을 그대로 써도 됩니다:
   - `강남역 분석해줘`
   - `여기서 뭐하면 좋을까?`
   - `홍대랑 비교해줘`
   - `여기 창업하면 위험해?`
   - `카페 열면 매출 얼마나?`
4. 답변 하단의 **추천 질문 칩**을 눌러 이어서 물어보면 더 깊은 분석으로 이어집니다.

## 4. 팁

- **자연어로 편하게** 물어보세요. "강남역 유동인구가 언제 제일 많아?" 같은 대화형 질문도 이해합니다.
- **상권을 먼저 고르지 않아도** 질문에 상권명이 있으면 자동으로 인식합니다.
- 응답 하단에 항상 **데이터 기준 분기**와 **출처**(서울 열린데이터광장)가 표시됩니다.
- 분석 결과는 참고용입니다. 실제 창업·투자 의사결정은 현장 확인과 병행하세요.
