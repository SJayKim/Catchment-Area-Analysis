# Screenshots

UI 상태/테스트 증거로 남기는 스크린샷 모음 (~64MB). 4개 카테고리로 분류.

| 폴더 | 용도 |
|---|---|
| `dev/` | 개발 중 UI 캡처 (디자인 검토, 컴포넌트 시연) |
| `e2e-qa/` | E2E QA 실행 결과 캡처 (케이스별 증거) |
| `real-mode/` | Real 데이터 모드 실행 시 캡처 |
| `ux/` | UX 시나리오 (시연용, 데모) |
